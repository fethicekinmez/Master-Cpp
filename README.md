## Prerequisites

- C++ compiler (g++ recommended)
- Basic understanding of programming concepts

## How to Run

Each directory contains a standalone example with its own `main.cpp` file. To compile and run:

```bash
cd directory_name
g++ main.cpp -o main
./main
```

## Repository Structure

Each topic is organized in its own directory with:
- A main.cpp file containing the example code
- Compiled executable (main) for testing
